Explore Your Block: build plan

Team Explore your block · Games track · Build for Everyone, Wed 21 Oct 2026

The product in one line

One neighborhood outing app that reshapes for whoever is looking: kid spots for kids, hangouts for teens, a full planner for adults, and for a mixed group only the spots that work for everyone, under the youngest person's k-ID rules.

Visual prototype (the reference for every screen): explore-your-block.vercel.app/prototype.html
k-ID setup details: explore-your-block.vercel.app/kid-handoff.html

How it fits together

Browser (React + Vite)
  KidCoreProvider → KidSessionProvider → age gate (k-ID)
     pending  → "Waiting for a grown-up" screen
     pass     → our app screens, fed REAL permissions from k-ID
        Ollie talks        → /api/ollie/speak     (Inworld)
        "What can we do?"  → /api/voice/listen    (Modulate)
        Buy the pack       → FastSpring checkout  → /api/pack/webhook
     claimToken          → /api/kid/claim       (k-ID, secret key)

Vercel (same project): /api/* serverless functions hold every secret key

The front end and back end live in one repo and deploy together on Vercel. Secret keys live only in Vercel's environment variables, never in the code or the browser.

Build order

  1. React app + real k-ID age gate wrapping the prototype screens. Deploy. This alone is a working demo.
  2. /api/kid/claim with the secret key; permissions drive every screen.
  3. Ollie's real voice (Inworld) on "Find something red!" and the group answer.
  4. Voice input (Modulate) for "What can we all do?"
  5. FastSpring checkout for the Family Outing Pack (sandbox).

Stop adding features at 3:00 PM. 3:00 to 4:15 is fixing and rehearsing. Submit before 4:30 PM.

Keys: where they go

  • Vercel project → Settings → Environment Variables. Add each key there by name (table above).
  • For local runs, put them in a .env.local file that is listed in .gitignore. Never commit it.
  • The k-ID publishable key is the only key that may appear in front-end code.
  • Never paste keys into chat, Discord or the repo.
